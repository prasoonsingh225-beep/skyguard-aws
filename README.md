# SkyGuard-AWS

SkyGuard-AWS is a complete prototype for real-time anomaly detection in Automatic Weather Stations (AWS) using temperature, pressure, and humidity measurements. It combines a multivariate LSTM autoencoder, a FastAPI inference service, a live Streamlit dashboard, and a lightweight explainability pipeline.

The project is designed for the SIH / MoES use case where AWS observations can be affected by sensor faults, spikes, frozen values, communication loss, calibration drift, and extreme weather events. The model learns normal temporal patterns and flags abnormal behavior with a confidence score and an explainable summary.

Features
- Real-time multivariate anomaly detection for temperature, pressure, and humidity
- Synthetic AWS data generation with injected anomalies (spike, drift, frozen sensor, communication loss)
- LSTM autoencoder for normal pattern learning
- FastAPI prediction endpoint with scoring and severity levels
- Dashboard for alerts and monitoring
- SHAP-based model explanation example
- Edge/TFLite deployment plan for ESP32 / TinyML

Project structure
- data_generator.py: generates synthetic AWS data with anomaly injection
- utils.py: preprocessing, scaling, and score utilities
- train.py: trains the LSTM autoencoder and saves model + threshold
- serve.py: FastAPI service for online anomaly inference
- dashboard.py: Streamlit monitoring dashboard
- send_examples.py: client script to send sample measurements to the API
- explain_shap.py: SHAP explainability example
- edge/esp32_tflite_example.cpp: minimal TFLite inference example for embedded deployment
- edge/README.md: Edge deployment guide
- requirements.txt: dependency list

Quick start

1. Clone the repo and create a virtual environment

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. Generate synthetic AWS data

```bash
python data_generator.py --out data.csv --n 30000
```

3. Train the anomaly model

```bash
python train.py --data data.csv --model model.h5 --window 60
```

4. Start the prediction service

```bash
uvicorn serve:app --host 0.0.0.0 --port 8000
```

5. Send example readings to the API

```bash
python send_examples.py
```

6. Run the dashboard

```bash
streamlit run dashboard.py
```

Example API payload

```json
{
  "ts": "2026-09-26T12:00:00Z",
  "temperature": 36.4,
  "pressure": 1012.7,
  "humidity": 74.8
}
```

Example response

```json
{
  "score": 0.2846,
  "threshold": 0.18,
  "is_anomaly": true,
  "severity": "medium",
  "root_cause": "spike",
  "confidence": 0.74
}
```

Why this works
- Normal AWS time series are generated by seasonal and diurnal trends.
- The LSTM autoencoder learns the normal behavior of the joint temperature-pressure-humidity system.
- At inference time, a windowed sequence is reconstructed; large reconstruction error indicates abnormal behavior.
- The model is multivariate and can capture hidden inconsistencies across variables that simple thresholds often miss.

Deployment notes
- This prototype is suitable for local research and demo use.
- For large networks, deploy one-horizon prediction service per station with a central dashboard.
- For field deployment, export the model to TensorFlow Lite and quantize for ESP32 or microcontroller clusters.

SIH / MoES problem fit
- Detects abnormal AWS measurements in real time
- Identifies spikes, frozen values, drift, and communication failures
- Learns temporal patterns without needing heavy hand-crafted rules
- Provides explainability and anomaly explanations
- Compatible with a scalable station network
